    JAVA 8
 
 
1) Lambda Expressions & Method References
Lambda syntax: (args) -> expression / (args) -> { statements }
Target typing (type inference based on context)
Effectively final variables in lambdas
Method references:
Class::staticMethod
instance::instanceMethod
Class::instanceMethod (unbound)
Class::new (constructor reference)
Functional interfaces (single abstract method)
2) Streams API (java.util.stream)
Stream creation: Collection.stream(), Stream.of, Arrays.stream, Files.lines
Intermediate ops (lazy): map, filter, flatMap, distinct, sorted, peek, limit, skip
Terminal ops: forEach, collect, reduce, findFirst, findAny, anyMatch, allMatch, noneMatch, count.
3) Optional (java.util.Optional)
Creation: of, ofNullable, empty
Access: isPresent, ifPresent, orElse, orElseGet, orElseThrow
Transformation: map, flatMap, filter
Best practices: Avoid as fields/params; return type only. Prefer orElseGet for expensive defaults.
4) Date & Time API (java.time)
Core types: LocalDate, LocalTime, LocalDateTime, ZonedDateTime, OffsetDateTime, Instant
Durations & periods: Duration, Period.

5)  Functional Interface:
 
 A Functional Interface is an interface that contains exactly one abstract method.
💡 It can contain:
1 abstract method ✔
Any number of default methods ✔
Any number of static methods ✔
Methods from java.lang.Object ✔
📌 Marked with @FunctionalInterface (optional but recommended).
 
Because Java 8 introduced lambda expressions, and lambdas need a target type.
Functional interfaces provide that target.

                                                                            Spring JPA
 
 
1) What is Spring Data JPA? How is it different from JPA/Hibernate?
JPA: Specification (API contracts).
Hibernate: JPA implementation (provider).
Spring Data JPA: Adds repository abstraction (CRUD, query derivation, paging, auditing), reduces boilerplate.
2) Repository types and when to use them
CrudRepository<T, ID> – basic CRUD
JpaRepository<T, ID> – CRUD + paging + batch methods
PagingAndSortingRepository<T, ID> – adds pagination & sorting
Example:
 


public interface UserRepository extends JpaRepository<User, Long> {
    Optional<User> findByEmail(String email);
    List<User> findTop3ByStatusOrderByCreatedAtDesc(Status status);
}
3) Query derivation – method name rules
findBy, readBy, getBy
Combinators: And, Or, Between, LessThan, Containing, In, True, False, IsNull, IgnoreCase
Sorting: OrderBy<FieldName>Asc/Desc
🔹 @Query, Native Queries, and SpEL
4) When to use @Query?
Complex joins, partial selects (projections), performance tuning.
 


@Query("select u from User u join fetch u.roles where u.email = :email")
Optional<User> findWithRolesByEmail(@Param("email") String email);
 
5) Native queries & updates
 


@Modifying
@Query(value = "update users set status = :status where last_login < :cutoff", nativeQuery = true)
int bulkDeactivate(@Param("status") String status, @Param("cutoff") Instant cutoff);
 
6) SpEL in queries (dynamic parts)
 
 


@Query("select u from User u where u.tenantId = :#{#auth.tenantId}")
List<User> findAllByTenant(@Param("auth") AuthContext auth);
 
🔹 Pagination, Sorting, and Slices
 
7) How do you implement pagination?
 


Page<User> page = repo.findByStatus(Status.ACTIVE, PageRequest.of(0, 20, Sort.by("createdAt").descending()));
 
Page = results + total count (extra query)
Slice = results + hasNext (no count query) → more efficient for infinite scrolling
List = just results

                                                 Spring Security
Authentication vs Authorization
Authentication → Who are you? (verify identity)
Authorization → What can you do? (access control).
Security Context
Holds the current Authentication (principal + authorities). Propagated via SecurityContextHolder.
Filter Chain
A chain of servlet filters handling authentication/authorization. Ordered, stateless by default with JWT/sessionless APIs.
Where to configure now?
WebSecurityConfigurerAdapter is deprecated.
Use SecurityFilterChain bean and HttpSecurity DSL.
What is PasswordEncoder and why BCrypt?
PasswordEncoder hashes and verifies passwords. BCrypt is recommended because it’s adaptive, salted, and resists brute-force attacks.
What does UsernamePasswordAuthenticationFilter do?
Processes username/password login (by default /login), creates an Authentication token, and delegates to AuthenticationManager.
 What is OncePerRequestFilter?
A base class for custom filters that guarantees a single execution per request within a single request dispatch.
Difference between hasRole() and hasAuthority()?
hasRole("ADMIN") expects authority ROLE_ADMIN.
hasAuthority("ADMIN") matches exact authority string.
What is the ROLE_ prefix?
Spring treats roles as authorities with ROLE_ prefix. hasRole("X") internally checks for ROLE_X.
.permitAll() vs .authenticated()?
permitAll() → accessible without authentication.
authenticated() → requires a logged-in user.
Token expiration vs refresh token?
Access token: short-lived; used on each request. 
Refresh token: long-lived; used to obtain new access tokens without re-login.
Difference between 401 vs 403?
401 Unauthorized: Not authenticated or token invalid/missing.
403 Forbidden: Authenticated but not authorized.
Difference between CORS and CSRF?
CORS: Browser cross-origin policy; server decides which origins are allowed.
CSRF: Attack exploiting implicit authentication (cookies). CORS ≠ security; it’s a browser restriction.
